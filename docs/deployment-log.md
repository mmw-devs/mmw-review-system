# 部署记录

> 仅追加。每次部署（无论成败）追加一行。
> CI 在部署后会自动开一个只修改本文件的 PR（`codex/deploy-log-<RUN_ID>-<ATTEMPT>`）；
> 若仓库禁止 GitHub Actions 创建 PR，可从本次 run summary 手工补录。
> 服务器可连接时另追加记录（不保证防篡改）：`/opt/mmw-review-system/data/deployments.log`。
>
> 不要在本文件写入主机、IP、端口、密钥或令牌。
